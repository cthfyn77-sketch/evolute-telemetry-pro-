# Evolute Telemetry Pro

Независимое Android-приложение для локального мониторинга Evolute i-JOY.

## Принципы
- Исходный APK и старые репозитории не изменяются.
- Только read-only запросы к API Evolute; команды автомобилю не отправляются.
- Токены — только в Android Keystore AES-GCM.
- Телеметрия и история хранятся локально на устройстве.
- Реальные данные отделяются от расчётных.

## План реализации
1. Отдельная авторизация SMS и защищённая сессия.
2. Автоматический сбор телеметрии.
3. История SOC/одометра с интерполяцией на километровых отметках.
4. Прогноз запаса хода по последним 10 км; до накопления истории — штатный прогноз.
5. Поездки, зарядные сессии, графики, маршруты и аналитика.

## Сборка
GitHub Actions собирает debug APK и прикрепляет его к workflow run как artifact.
