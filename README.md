# Evolute Telemetry Pro

Android-приложение для локального мониторинга Evolute i-JOY. Package ID: `com.evolute.telemetrypro`.

## Авторизация и телеметрия на телефоне

- Вход в аккаунт Evolute по номеру телефона и SMS-коду непосредственно в приложении.
- Запрос SMS и получение токенов выполняются Android-клиентом через HTTPS API.
- Access/refresh tokens хранятся зашифрованными AES-GCM; ключ шифрования находится в Android Keystore.
- При истечении access-token приложение обновляет пару токенов через refresh endpoint. Если сессия отозвана или refresh-token больше не принимается, требуется повторный вход.
- Поиск автомобиля в аккаунте, получение IMEI и запрос телеметрии выполняются самим приложением.
- Коллектор работает в foreground service с периодом опроса 30 секунд и сохраняет снимки в локальную SQLite.
- Сохраняются SOC, одометр, штатный запас хода, online/ready, время обновления состояния API и разрешённый набор датчиков.
- GPS-координаты и маршрутные поля намеренно не собираются.
- Доступны локальная история, аналитика батареи, поездок и зарядных сессий.

## Важные ограничения и безопасность

- Приложение использует read-only reverse-engineered API `https://app.evassist.ru`; это не официальный публичный контракт производителя, endpoints могут измениться.
- CAPTCHA не обходится. Если API потребует CAPTCHA или дополнительную проверку, вход остановится и покажет ошибку.
- Используйте только собственный аккаунт. Не передавайте SMS-коды, access-token или refresh-token третьим лицам.
- Команды управления автомобилем не реализованы.
- Данные истории хранятся локально на телефоне. Токены не выводятся в логи.
- Android может ограничивать фоновую работу. Сервис использует постоянное уведомление и `START_STICKY`; после остановки ОС сбор возобновляется при следующем открытии приложения.
- API может ротировать refresh-token. Вход и сбор должны выполняться внутри этого приложения; параллельное использование одной сессии другим клиентом может сделать refresh-token недействительным.

## Расчёт запаса хода

- До накопления достаточной истории используется штатный прогноз автомобиля.
- Дальнейший прогноз рассчитывается по фактическому изменению SOC и одометра на валидных участках; зарядка, офлайн-снимки и разрывы исключаются согласно правилам анализатора.
- Все расчёты выполняются на локально сохранённых снимках.

## Сборка и проверки

GitHub Actions запускает unit-тесты. Сборка APK должна запускаться отдельным ручным workflow только после проверки конфигурации подписи и готовности ключа. Debug APK не является релизом и не подходит для обновления приложения, подписанного другим сертификатом.

## Постоянная подпись

Для подписанного Release APK необходим один постоянный keystore. Его нельзя хранить в репозитории. В CI должны быть настроены защищённые GitHub Secrets для Base64 keystore, store password, key alias и key password. SHA-256 сертификата итогового APK нужно сверять с заранее зафиксированным отпечатком. Без подтверждённого keystore и совпадающего отпечатка выпуск подписанного APK не считается готовым.
