# Evolute Telemetry Pro

Отдельное Android-приложение для локального мониторинга Evolute i-JOY. Package ID: `com.evolute.telemetrypro`.

## Уже добавлено в проект
- Отдельный Compose-интерфейс в тёмном Pro-стиле.
- SMS-авторизация через read-only API EVACONNECT.
- Хранение access/refresh token в AES-GCM с ключом Android Keystore.
- Отдельная SQLite-база локальных снимков телеметрии.
- Foreground-сервис, автоматический запуск после успешной авторизации и повторный запуск при следующем открытии приложения.
- Опрос телеметрии раз в 30 секунд.
- Получение SOC, одометра, штатного запаса хода, статуса online/ready и выбранных реальных датчиков.
- Расчёт запаса хода по SOC, интерполированному на целых километровых отметках, с окном 10 км. Во время зарядки окно сбрасывается; до накопления валидной истории используется OEM range.
- Журнал поездок на основе локальных снимков: начало при READY ON и подтверждённом движении по одометру либо GPS (порог GPS 500 м с подтверждением несколькими снимками).
- Завершение поездки: READY OFF запускает 10-минутное окно; подключение зарядного разъёма сохраняет текущую поездку даже при отложенной зарядной сессии; после отключения разъёма даётся 15 минут на READY ON и возобновление движения.
- Состояния ожидания и таймеры хранятся в SQLite, поэтому переживают перезапуск сервиса/приложения; в журнале отображается текущая стадия поездки.
- В карточке поездки сохраняются время, начальный/конечный одометр, SOC и доступные конечные координаты; незавершённая поездка восстанавливается после перезапуска сервиса.
- Unit-тесты расчётного алгоритма и сохранения истории поездок.
- GitHub Actions: тесты и сборка debug APK как artifact.

## Безопасность и ограничения
- Исходный APK и старые репозитории не изменяются.
- Package ID, база и Keystore alias нового приложения отдельные.
- Только чтение API. Команды автомобилю не отправляются.
- Токены не включаются в логи, CSV или исходники.
- Данные остаются на устройстве.
- Android может ограничивать фоновую работу. Сервис использует постоянное уведомление и START_STICKY; если ОС или пользователь остановили приложение, повторный запуск гарантируется при следующем открытии приложения. Автоматический старт foreground dataSync сервиса из BOOT_COMPLETED не используется из-за ограничений новых версий Android.

## Сборка
Workflow `.github/workflows/android.yml` выполняет `gradle testDebugUnitTest assembleDebug` и публикует `app-debug.apk` как artifact `evolute-telemetry-pro-debug`.
